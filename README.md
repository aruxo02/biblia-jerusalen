# Biblia de Jerusalén — web de la app

Página de presentación, política de privacidad y ayuda de la app **Biblia de Jerusalén**
para Android e iOS, publicada con GitHub Pages:

- Presentación: https://aruxo02.github.io/biblia-jerusalen/
- Política de privacidad: https://aruxo02.github.io/biblia-jerusalen/privacidad.html
- Ayuda (URL de asistencia): https://aruxo02.github.io/biblia-jerusalen/ayuda.html
- Ficha para las tiendas: https://aruxo02.github.io/biblia-jerusalen/tienda/

## Qué hay

| Ruta | Contenido |
| --- | --- |
| `index.html` | Presentación de la app |
| `privacidad.html` | Política de privacidad (la que piden Google Play y App Store) |
| `ayuda.html` | Preguntas frecuentes y contacto |
| `tienda/` | Textos para copiar, respuestas a los cuestionarios, icono, gráfico destacado y capturas |
| `css/`, `fuentes/`, `img/` | Estilos, letras (Literata e Inter, licencia OFL) e imágenes |

Es HTML estático, sin dependencias ni compilación: se edita el fichero y GitHub Pages lo
publica en un minuto.

## Activar GitHub Pages (una sola vez)

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch:
**main** y carpeta **/ (root)** → Save.

## Cuando la app esté publicada

En `index.html`, cambia los dos botones «Muy pronto» por los enlaces de Google Play y del
App Store (hay un comentario justo encima que indica cómo).
